# V4max3pro 方案（实事求是）

## 1. 基线（不可动摇）

| 项 | 值 |
|---|---:|
| 基线提交 | `submissions/submission_v4_max3.csv`（来自 zcode-v4-max3） |
| 公开榜 | **0.71222**（用户实测） |
| 本地嵌套 OOF | **0.70307** |
| 配方 | `max(merger_ord8, v2_cat_alt8, mine_noxb_es)` |
| 已校准 CV→LB | **+0.00915** |

目标公开榜 0.7155 ⇒ 按同一校准大约需要嵌套 **≈0.70635**（相对 max3 约 **+0.00328**）。

这是很大的一步。本方案**不承诺**一定打到 0.7155；只承诺：
- 不改考评折数刷本地分（V3 教训）
- 不伪造本地分、不把选择乐观当真实增益（V5 教训）
- 只有相对 max3 有可解释、可复现的提升时才建议提交
- 今天只剩 1 次提交：达不到门槛就明确建议**不交**

## 2. 已验证的事实

1. max3 三臂高度相关（Spearman ≈0.95–0.97），但 `max` 仍有效。
2. V5 的新编码世界（w4/w5/w7/w8/w9/w10/w11）加入 max3 后嵌套**下降**——不能再走那条路。
3. 现成库存里，唯一明显帮助 max3 的是 **V10 plus**（保留 x0–x18 的正交臂）：
   - 单臂 OOF ≈0.6886（弱）
   - `max(max3, plus)` 嵌套 **0.70429**（**+0.00122**）
   - `max(max3, b7_closest)` 嵌套 **0.70449**（+0.00142，含已知 ES/选择乐观）
4. gpt56 建议：增益应来自**编码世界 / 有效训练量 / 结构多样性**；种子 8→12 已饱和；公开榜只做最终确认。

## 3. 迭代杠杆（按优先级）

| ID | 动作 | 假设 | 晋级门槛 |
|---|---|---|---|
| P0 | 冻结 max3 三臂 + 提交为对照 | 复现 0.71222 配方 | 与官方提交秩相关 ≈1 |
| P1 | 第 4 臂：强化 plus（5 折 + Ordered/ES，不改 max3 尺子） | plus 的正交性可保留，同时抬高单臂强度 | 单臂 ≥0.690；加入 max 后嵌套 ≥ max3+0.001；与三臂 max corr ≤0.96 |
| P2 | 主臂测试端 ES 升级（merger/alt 允许 eval_set；OOF 分开报） | 与 mn_es 同逻辑：OOF 可乐观，测试预测仍诚实 | 全量含 ES 嵌套 ≥ max3+0.0015；诚实-only 不倒退太多 |

**禁止**：把 5 折改成 10 折当主配方；看榜回调参；用全量 OOF 临时调权。

## 4. 提交门槛（预登记）

仅当同时满足才建议使用今天唯一提交名额：

1. 相对 max3，**同一 5 块嵌套尺子** Δ ≥ **+0.0015**（含 ES 臂的 full_nested 可报，但必须并列报告诚实口径）。
2. 与 `submission_v4_max3.csv` 的测试 Spearman ∈ **[0.97, 0.999]**（有实质改动但未换皮）。
3. 打乱标签 sanity：融合 OOF AUC ∈ 0.47–0.53。
4. 文档写清每只臂是否含 ES / 是否 10 折，以及预期 LB 区间（用 max3 校准 ± 噪声）。

若 full_nested 只到 ~0.7043（max3+plus），按 +0.00915 校准预期 LB ~**0.7134**，距 0.7155 仍差 ~0.002——**不够冲 0.7155**，除非 P1–P2 再抬一截。
