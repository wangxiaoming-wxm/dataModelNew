## 一、fp_v8 未过审，不要交

`submission_fp_v8_champion.csv`（`fa2a06f4…`）声称 OOF 0.77016 / nested 0.77033。
独立复算后：**这两个数字都是假的**。完整证据 `docs/FP_V8_AUDIT.md`，三条最硬的：

1. 它的 "nested" 只是把做好的 OOF 切五块再平均。把 `y + 噪声`（100% 泄漏）喂进去，
   它报 **nested = 1.0** 并放行。这个门禁检测不出任何过拟合。
2. 它对约 **1 万个 TE 键用全体标签选方向**，再在同一批标签上评分。
   键越多虚增越大：8 键 +0.022，224 键 **+0.13**。这是选择偏差的指纹。
3. **把 train 的 id 随机打乱后重跑，它汇报的分数一模一样**
   （0.6249 → 0.6278，0.5964 → 0.5945，20 次置乱全部落在波动内）。
   在随机数据上能复现的量，测的不是数据。

另外 id 是均匀 64-bit 哈希，**train/test id 交集 = 0** —— 就算真记住了也搬不过去。
fp_v8 按权重只有 **10.6%** 是真模型，其余 89.4% 是 id 噪声池。

**预期线上 0.685 ~ 0.705。**

## 二、这一轮最重要的发现（请先看这条）

> **"和已交文件 Spearman < 0.97" 和 "线上超过 0.71503"，在这份数据上基本互斥。**

我独立造了 3 个特征世界 × 5 个模型家族 = **12 条臂，4 个全新 seed，240 个模型**：

* 在**未参与筛选**的 seed 上，没有任何融合能超过 vz19 内核，最好 **+0.00012**；

**两个好模型在同一份数据上必然互相同意。** 想把 rho 压到 0.97 以下，代价实测是
**−0.014 ~ −0.020 AUC**（`docs/VZ21_METHOD.md` 第 5 节有完整代价曲线）。
而 W62 距离前三线只有 **+0.005**。**多样性的代价是这个差距的 3 倍。**
