# 实验记录（含所有走过的死路）

这份文件的目的：让接手的人**不用重跑我跑过的每一个对照**，也不要再去踩已经证明无效的方向。

所有数字都在同一套协议下产生：分层 5 折 × N 次重复，**固定树数、不在外层验证折上早停**。
两列的含义：

- `single` = 每次重复各自的 OOF AUC 再取平均（单模型强度）；
- `bag` = 把各次重复的 OOF 秩平均之后再算 AUC（部署时集成的代理指标，也是最终关心的指标）。

脚本在 `exp/`，训练日志在 `logs/`。

## 1. 特征集：删掉噪声列有用，但远不是全部

### exp01 LightGBM，5 折 × 4 重复

| 特征集 | 列数 | AUC（各重复均值） |
|---|---:|---:|
| 原始全量 | 50 | 0.61989 |
| 删掉匿名化噪声列 | 28 | **0.62448** |
| 再删 `livability` | 27 | 0.62355 |

### exp03 CatBoost，5 折 × 2 重复

| 特征集 | 迭代数 | AUC |
|---|---:|---:|
| 原始全量 | 400 | 0.65384 |
| 原始全量 | 900 | 0.64656 |
| 删掉噪声列 | 400 | **0.66230** |
| 删掉噪声列 | 900 | 0.66036 |

CatBoost 比 LightGBM 高 3–4 个点，差距全部来自它对类别列的有序目标统计量。
**结论：主力模型必须是 CatBoost，类别交叉必须显式喂给它。**

### exp06 逐块消融，CatBoost，5 折 × 4 重复

| 特征集 | 列数 | single | bag |
|---|---:|---:|---:|
| core（13 列：days/condition/age + 8 开关 + region + source） | 13 | 0.66126 | 0.66519 |
| core + month/version/grades | 16 | 0.66054 | 0.66403 |
| core + x18 | 14 | 0.65981 | 0.66412 |
| core + t3n/x20 | 16 | 0.65920 | 0.66304 |
| core + 全部噪声列 | 44 | 0.66077 | **0.66689** |

注意最后一行：加回噪声列在 `bag` 口径上反而最高。当时以为是巧合，
后来（exp12）证明这是本数据最大的一个机制。

## 2. 交互筛查：`source × condition` 一枝独秀

### exp08 用诚实折外目标编码逐对筛查

判据是"交叉项的 AUC" 减去 "两个主效应 logit 相加后的 AUC"。正的才说明存在真交互。

| 交叉 | 类别数 | 交叉 AUC | 可加 AUC | 增益 |
|---|---:|---:|---:|---:|
| `source × cond_q10` | 110 | 0.5954 | 0.5661 | **+0.0292** |
| `cond_q10 × bin_pat` | 892 | 0.5673 | 0.5544 | +0.0129 |
| `region × age_cat` | 167 | 0.5599 | 0.5487 | +0.0113 |
| `month × version` | 215 | 0.5158 | 0.5048 | +0.0110 |
| `age_cat × bin_pat` | 706 | 0.5294 | 0.5204 | +0.0090 |
| `source × days_q10` | 110 | 0.6047 | 0.6017 | +0.0030 |
| `region × days_q10` | 200 | 0.6082 | 0.6055 | +0.0027 |
| … | | | | |
| `days_q20 × version` | 380 | 0.5718 | 0.5986 | −0.0268 |
| `cond_q10 × version` | 190 | 0.5271 | 0.5519 | −0.0248 |
| `days_q20 × bin_pat` | 1362 | 0.5723 | 0.5956 | −0.0233 |

`month × version` 那一项要当心：两个主效应本身都是噪声（诚实 OOF-TE ≈ 0.50），
两个噪声交叉出来的"增益"多半也是噪声，不要照抄。

`source × condition` 这一项后来变成了 `cond_r = condition / median(condition | source)`，
以及 `ratio = days / cond_r`（单列 AUC 0.620，全数据最强）。

### 变换扫描（约 40 个候选）

对 `days`、`condition`、`cond_r`、`age`、`grade` 之间的比值 / 乘积 / 秩差，
以及按 `source`/`region`/`reg×src`/`age`/`version`/`month` 的秩归一化、中位数归一化、
z 归一化都扫过。峰值就是 `ratio`，没有别的组合超过它：

| 特征 | AUC |
|---|---:|
| `days / cond_r` | **0.6197** |
| `days × (1 − cond 在 source 内的秩)` | 0.6216 |
| `days / cond_r^0.75` | 0.6211 |
| `days / condition`（不归一化） | 0.6043 |
| `days` | 0.5932 |
| `condition` | 0.5324 |

也扫过 `days` 的周期性（mod 7 / 30 / 90 / 365 / 365.25、小数部分、与 `month` 的加减组合），
**全部无信号**（最高的 `days mod 90` 是 0.518，在噪声带内）。

## 3. 交叉数量：多了反而掉

### exp09 CatBoost，5 折 × 2 重复，同一次拟合里评估多个树数

| 手工交叉规模 | 特征数 | 类别列数 | 最佳 (single, bag) |
|---|---:|---:|---|
| 只用精选交叉 | 66 | 42 | **(0.67909, 0.68210)** @500 |
| + 6 列基做全配对 | 81 | 57 | (0.67785, 0.68080) @500 |
| + 10 列基 | 111 | 87 | (0.67594, 0.67885) @700 |
| + 13 列基 + 4 个三阶 | 148 | 124 | (0.67659, 0.67984) @700 |
| + 16 列基 + 8 个三阶 | 194 | 170 | (0.67432, 0.67775) @700 |

**结论：精选交叉 > 全配对。**盲目扩交叉每加一批就掉 0.002 左右。

### exp11 让 CatBoost 自己组合类别列，能不能替代手工交叉？

| 配置 | 特征数 | 类别列数 | 最佳 (single, bag) |
|---|---:|---:|---|
| 只有数值列 | 22 | 0 | (0.64893, 0.65044) |
| 低基数类别列，`max_ctr_complexity=2` | 49 | 27 | (0.65736, 0.65897) |
| 低基数类别列，`max_ctr_complexity=4` | 49 | 27 | (0.65741, 0.65905) |
| 低基数类别列，`max_ctr_complexity=6` | 49 | 27 | (0.65711, 0.65875) |
| 手工交叉，`max_ctr_complexity=2` | 74 | 52 | (0.67203, 0.67511) |
| 手工交叉，`max_ctr_complexity=4` | 74 | 52 | (0.67452, 0.67777) |

**不能替代。**`max_ctr_complexity` 怎么调都没用（2/4/6 差别在 0.0005 内），
但手工把交叉物化出来直接 +0.017。原因大概是 CatBoost 的自动组合是贪心的，
不会主动去找 `condition × source` 这种需要先归一化才显形的交互。

## 4. 真正的大跳：多套扰动重编码

### exp12 把主办方的冗余噪声编码加回去

| 特征集 | 特征数 | 类别列数 | 最佳 (single, bag) |
|---|---:|---:|---|
| 干净交叉集 `cross2` | 98 | 66 | (0.67934, 0.68225) @500 |
| `cross` + 噪声视图 | 86 | 58 | (0.68817, 0.69130) @500 |
| `cross2` + 噪声视图 | 117 | 81 | **(0.68921, 0.69209)** @500 |

**+0.010。**这是整个项目里单笔收益最大的一步，而这些列本身零信号（见 `docs/DATA_STRUCTURE.md` 第 5 节）。

### exp13 自造抖动重编码（`src2/jitter.py`）

| 配置 | 最佳 (single, bag) |
|---|---|
| 噪声视图 + 2 套抖动 | (0.68860, 0.69160) @600 |
| 噪声视图 + 4 套抖动 | **(0.69028, 0.69386)** @800 |
| 只用 4 套抖动，不要主办方噪声列 | (0.68032, 0.68333) @600 |

自造抖动能复现这个机制（单独用也比干净集高 +0.001），
但**替代不了主办方那批列**——它们的扰动尺度是和真实变量匹配好的。两者叠加最好。

### exp14 每个模型换一套抖动流 + 深度

| 配置 | 最佳 (single, bag) |
|---|---|
| 4 套抖动，所有模型共用 | (0.68717, 0.69018) @600 |
| 4 套抖动，**每个模型一套不同的** | (0.68884, 0.69223) @800 |
| 6 套抖动，每模型不同 | (0.68788, 0.69145) @800 |
| 4 套，每模型不同，depth 7 | (0.68764, 0.69103) @1000 |
| 4 套，每模型不同，depth 5 | **(0.69024, 0.69388)** @1000 |

到这一步各配置的差距（±0.003）已经进入噪声区间，所以停止微调，
定为 depth 5 / 1000 树 与 depth 6 / 700 树两个子臂，改去做集成。

### exp15 早停偏差的精确测量

`train_b5_focus.CAT_PARAMS` 里 `eval_metric="AUC"` + `od_wait=150` + `use_best_model=True`，
也就是在 1400 次迭代里直接挑让这一折 AUC 最高的点，再拿这一折的预测去报分：

| 停止方式 | 单种子 OOF AUC |
|---|---:|
| 按验证折 **AUC** 早停 | 0.68710 |
| 按验证折 Logloss 早停 | 0.68692 |
| 固定 500 树，完全不看验证折 | 0.68456 |

**乐观偏差 = +0.00254**（选中的迭代数：435 / 272 / 429 / 372 / 222）。

## 6. 集成

### 种子 bagging 的收益（exp05，LightGBM）

| 重复次数 | 秩平均后的 AUC |
|---:|---:|
| 1 | 0.63568 |
| 2 | 0.63856 |
| 4 | 0.63953 |
| 8 | 0.64165 |
| 10 | 0.64203 |

前几次收益明显，之后迅速饱和。CatBoost 上同样：三个主臂从 8 个种子加到 12 个，
`views_max` 只从 0.69958 动到 0.69910（噪声内）。

### 多臂融合

臂间秩相关和最终融合表见 `docs/RESULTS.md`。三条要点：

1. 只改 CatBoost 深度**不算多样性**（`cat_d5 ~ cat_d6` 相关 0.997，融合几乎无增益）；
2. 换**编码世界**才算（`cat_alt` 相关 0.954，把 `cat_pair_max` 的 0.69539 抬到 `views_max` 的 0.69910）；
3. 换**模型族**在这份数据上没用（`lgb_te` 0.671、`glm` 0.665，都太弱，进融合是负贡献）。

## 7. 明确无效 / 不要再试的方向

| 方向 | 结果 | 备注 |
|---|---|---|
| 把 `x0`–`x17` / `cc` / `max_g` / `V` 的组内残差当特征 | 联合 LightGBM CV 0.518 | 纯噪声，见 DATA_STRUCTURE 第 5 节 |
| `days` 的周期性（mod 7/30/90/365）| 最高 0.518 | 无 |
| `id` 哈希、行序 | 0.494 / 0.491 | 无泄漏可用 |
| 类别列的计数编码当主特征 | `count(region)` 0.548，其余 ≈0.50 | 只是 region 的粗编码 |
| 盲目扩到 170 个类别交叉 | −0.005 | 见 exp09 |
| 调 `max_ctr_complexity` | ±0.0005 | 见 exp11 |
| LightGBM / XGBoost / 逻辑回归当主力 | 0.62–0.67 | 差 CatBoost 3 个点以上 |
| LightGBM / GLM 臂进融合 | 负贡献 | 见 RESULTS 融合表 |
| 加 depth 7 的 CatBoost | −0.003 | 见 exp14 |
| 6 套抖动（比 4 套更多） | −0.002 | 见 exp14 |
| 第三套编码世界 `cat_alt2` | 单臂 0.691，进 `max` 反而 −0.0007 | 解耦够好但强度差 0.004；`max` 对弱臂敏感 |
| 种子从 8 加到 12 | ±0.0005 | 已饱和 |
| 用对抗验证找分布偏移 | train vs test AUC 0.4977 | 完全随机切分，没有偏移可利用 |
