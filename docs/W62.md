# W62 提交方案（可复核）

## 一句话

在**冻结**的 best_v1 双臂（main / alt）上，用预注册权重做线性融合：

```text
score = 0.62 * main + 0.38 * alt
```

主提交：`submissions/submission_w62.csv`  
（字节级等同于先前的 `submissions/submission_interim_w62.csv`，本分支两份都保留）  

本地 pooled OOF：**0.70159**（对照同臂 max2 = 0.70128，Δ ≈ +0.00032）  
**线上 AUC（已提交）：0.71503**（高于 max2 冠军锚点 0.71453）  
SHA-256：`e84bd2f0a9f47f58f11d32d914ed1f4f19e12cc8c6c3373e94afc17cba227fe5`

## 与冠军 max2 的关系

| 项 | max2（`submission_super714.csv`） | W62 |
|---|---|---|
| 臂来源 | 同一套冻结 best_v1 | 同一套冻结 best_v1 |
| 融合 | `max(rank_main, rank_alt)` | `0.62*main + 0.38*alt` |
| 本地 OOF | 0.70128 | **0.70159** |
| 文件 | 线上锚点 0.71453 原版 | **不同哈希**（Spearman≈0.993） |

W62 **不是**重训模型；是融合规则差异，因此秒级可复现，且提交文件与公开 max2 不同。
