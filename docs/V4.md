# V4 方案（进行中）

> 分支：`cursor/honest-auc-v4-145a`  
> 基线：V3 诚实嵌套 OOF **0.70124**（`docs/V3.md`，本分支不改动 V3 产物）  
> 目标：诚实嵌套 OOF（20 block seed 均值）**≥ 0.707**，且独立监督者全部诚实性门通过

V4 在 V3 的同一套诚实协议上继续推：不解冻早停、不碰测试标签、融合规则先登记再看分、

## 2. 协议红线（继承 V3，监督者强制）

1. 外层验证折上不许早停或做任何选择；树数开跑前定死。
2. 特征工程不许碰标签；分位 / 车型量纲 / 抖动流均为 label-free。
3. 融合规则先登记再看分；主报是多 block seed 嵌套均值。
4. 打乱标签必须回落到 ~0.5。
5. 不把榜单分当调参反馈；不读测试集标签。

`src4/audit_v4.py --target 0.707` 未达标则 `target_reached` 失败——设计如此。
