# GPT-5.6 下一阶段调优总路线

## 1. 当前基线与目标

### 1.1 已确认的基线

| 项目 | 数值 | 证据 |
|---|---:|---|
| 当前提交 | `submissions/submission_v2.csv` | `artifacts/v2/fusion_report.json` |
| 公开榜 AUC | **0.70878** | 用户提供的实际提交结果 |
| 本地嵌套 OOF AUC | **0.69856** | `artifacts/v2/fusion_report.json` |
| 同一规则全量 OOF AUC | 0.69910 | `views_max` |
| 上一版 B7 公开榜 AUC | 0.70722 | `README.md` |
| v2 相对 B7 的公开榜增量 | **+0.00156** | 两次真实提交的差值 |

`submission_v2` 是可信基线，但旧文档中“本地分加约 0.01 即为榜单分”的映射不能继续使用。
公开榜只是测试集子集，仓库估算半榜 AUC 标准差约 0.015；单次 `0.70878` 既不能证明
`views_max` 的全部本地增益都能迁移，也不能证明它失效。下一阶段只使用：

1. 同一批折、同一批种子的配对差值；
2. OOF 上的 bootstrap 差值区间；
3. 预先写死的晋级门槛；
4. 少量榜单提交作为最终确认，而不是调参反馈。

### 1.2 调优目标

- 第一目标：把可复现的本地诚实 AUC 提升 **至少 +0.003**；
- 冲刺目标：累计提升 **+0.005～+0.008**，但不同实验的增益不可直接相加；
- 风险目标：任何最终候选在配对 bootstrap 下，相对 v2 的 `P(ΔAUC > 0)` 应不低于 90%；
- 榜单目标：提高 `0.70878` 的期望值，不承诺某个具体公开榜分数。

## 2. 为什么继续沿用现有方案

现有方案最有价值的部分不是某组 CatBoost 参数，而是已经由消融实验确认的结构：

- `condition` 必须按 `source` 归一化；
- `days / cond_r` 是最强单一排序特征；
- 显式类别交叉远强于让 CatBoost 自动搜索交叉；
- 主办方噪声副本和可控 jitter 的价值是降低有序目标统计量方差；
- 真正的模型多样性来自不同“编码世界”，不是把深度从 5 改到 6；
- 固定树数、折外预测和嵌套融合避免了旧方案的早停乐观。

因此下一阶段不推翻 v2，而是围绕两个已暴露的瓶颈优化：

1. **每个模型只看到 80% 训练数据；**
2. **编码世界仍少，目标统计量方差仍高。**

## 3. 分阶段路线

| 阶段 | 目的 | 主要动作 | 晋级条件 | 优先级 |
|---|---|---|---|---:|
| S0 | 建立不会自欺的实验尺子 | 保存逐种子/逐折原始概率；配对 CV；bootstrap 差值；冻结实验登记表 | 基线可重复，所有候选可算配对差值 | 最高 |
| S1 | 用现有资产获得低成本增益 | v2 与冻结 B7 预测做受限融合；检验 `max`、rank mean 的稳定性 | 嵌套/配对增益 ≥ 0.0015，且下分位风险不恶化 | 高 |
| S2 | 提高单模型有效训练量 | 同种子 5 折 vs 10 折严格配对；通过后扩到 6～8 种子 | 2 种子配对增益 ≥ 0.002，完整运行仍为正 | 高 |
| S3 | 扩充强且解耦的编码世界 | 修复 alt2；新增 robust/rank/quantile 世界；两级筛选 | 单臂 ≥ 对照 −0.0015，相关 ≤0.96，融合增益 ≥0.001 | 高 |
| S4 | 增加合法结构多样性 | 概率平均 vs 秩平均；预登记树数分布；折内编码平均 | 配对增益 ≥0.001，至少 3/4 重复为正 | 中 |
| S5 | 建立正交低方差臂 | 经验贝叶斯 TE + GAM/正则 GLM，只作为融合臂 | 单臂 ≥0.685，且与主臂相关 ≤0.93，融合为正 | 中 |
| S6 | 冻结并选择最终提交 | 候选 Pareto 前沿、bootstrap 风险、提交预算 | 满足统一提交门槛 | 必做 |

## 4. 资源分配

建议把总算力按以下比例分配：

- 15%：S0 与所有基线复现；
- 25%：S2 的 10 折容量验证；
- 40%：S3 编码世界筛选和补种子；
- 10%：S4 结构 bagging；
- 10%：S5 正交臂；达不到门槛立即停止。

停止继续增加普通种子：现有证据显示 8→12 种子变化在 ±0.0005 内。算力应换成更高折数或新编码世界。

## 5. 统一实验门槛

每个实验都必须记录：

```text
experiment_id
parent_baseline
hypothesis
code_commit
data_sha256
folds_and_seeds
single_seed_auc
bagged_oof_auc
paired_delta
bootstrap_ci_90
rank_correlation
elapsed_sec
decision
```

候选进入下一阶段必须同时满足：

1. 与父基线完全相同的数据、折和种子；
2. 主指标为配对 OOF AUC 差值，不比较不同运行的裸 AUC；
3. 快筛 `ΔAUC ≥ +0.0015`，或 `ΔAUC ≥ +0.0008` 且与现有臂秩相关 ≤0.94；
4. 至少 3/4 个重复方向一致；
5. 打乱标签检查回到 0.47～0.53；
6. 最终融合用嵌套选择或冻结规则，不能看全量 OOF 后临时调权重。

## 6. 预期结果与风险

最值得期待的组合是“10 折主臂 + 2～3 个强编码世界 + 冻结 B7 多样性臂”。
若三个方向都通过门槛，合理目标是获得 **+0.003～+0.006 的可复现 OOF 增益**。
这通常足以提高榜单期望，但公开榜单次波动可能大于模型增益，因此不能用一次榜单下降否定实验。

主要风险：

- 从大量编码世界中挑最好者会产生选择乐观，必须两级筛选或嵌套选择；
- `max` 融合会放大弱臂尾部错误，新臂不够强时只能做小权重平均；
- 10 折增加模型训练量，也增加 80% 机时，必须先做同种子小试；
- B7 OOF 含已知早停乐观，只能作为冻结多样性臂，不能用其绝对 OOF 给收益背书；
- 公开榜仅用于确认最终候选，不反向修改参数。
