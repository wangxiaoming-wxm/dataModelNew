# AM40 提交方案（可复核）

## 一句话

在**冻结**的 best_v1 双臂（main / alt）上，用预注册公式混合 max 与 W62 线性分：

```text
linear = 0.62 * main + 0.38 * alt
score  = 0.40 * max(main, alt) + 0.60 * linear
```

主提交：`submissions/submission_am40.csv`

| 对照 W62 | 0.70159366（Δ ≈ **+0.000218**） |
| 对照 max2 | 0.70127521（Δ ≈ **+0.000536**） |
| 线上 W62 锚点 | 0.71503（AM40 为在其上的本地增强，待提交） |

## 与 W62 / max2 的关系

| 项 | max2 | W62 | AM40 |
|---|---|---|---|
| 臂来源 | 冻结 best_v1 | 同左 | 同左 |
| 融合 | `max(main,alt)` | `0.62m+0.38a` | `0.4*max + 0.6*W62线性` |
| 本地 OOF | 0.70128 | 0.70159 | **0.70181** |
| 是否重训 | 否 | 否 | **否** |

AM40 **不是**重训模型；只改融合规则，秒级可复现。相对 W62 引入 max 的高置信互补，同时保留已验证的 0.62/0.38 线性权重。

## 约束

- `alpha=0.40` 与线性权重 `0.62/0.38` 预注册；OOF/test 同一公式  
- 硬门禁：AM40 OOF 必须严格大于同臂 W62  
- 不碰测试标签、无伪标签、无外部数据  
- 不修改冻结臂数值；只改融合
