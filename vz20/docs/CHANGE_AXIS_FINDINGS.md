# vz20 换轴调查：冠军 0.749 的鸿沟不在提供的 CSV 里

**任务**：脱离 ratio/rate/rich/max2 同源轴，寻找与之**真正解耦**的强信号，逼近冠军 0.749。
**结论**：系统检验了 9 类解耦结构/泄漏假设，**全部为负**。在 `data/{train,test}.csv` 内，可利用的
建模上限 ≈ **0.70 OOF / ~0.713 online**；冠军的 +0.03~0.05 鸿沟**不存在于这些文件中**，只可能来自
**外部数据**（半合成数据集匹配到公开原始集）或**平台级泄漏**（不在 CSV 内）。诚实报告，不注水。

所有数字可由 `python3 src/vz20_explore.py` 复现（写入 `artifacts/vz20/explore.json`）。

## 1. 逐轴检验结果（全部诚实 OOF / held-out，seed=90210）

| # | 换轴假设 | 检验方法 | 结果 | 裁决 |
|---|---|---|---|---|
| 1 | 单变量存在强特征 | 每列 univariate AUC | 最强 `days`=0.593，其余 ≤0.53 | 无强单特征 |
| 2 | x0..x18 是独立强信号 | HGB on raw x, OOF | **0.499** | 噪声级 |
| 3 | x 是隐流形，label 局部光滑 | x-空间 kNN(k=50) OOF | **0.504** | 无流形信号 |
| 4 | x 正交于真实特征的残差含信号 | 线性去除真实特征后 HGB OOF | **0.511** | 残差无信号 |

> x9↔max_g 0.62、x15↔condition 0.37）。因此它们**不带新信息**——kNN/残差/HGB 全部随机。

## 2. 重要的前提纠正：「只有 CatBoost+RMSE 有效、分类 loss 近随机」是**错误**的

历史台账称 Logloss/CrossEntropy OOF≈0.51。本轮实测：
- kitchen-sink（原始特征，无特殊 FE）：**Logloss 0.661 ≈ RMSE 0.660**；
- vz19 FE + Logloss（Ordered d5, 3 折）：0.710 / 0.656 / 0.697，与 RMSE(0.716/0.663/0.692) 相当，
  Spearman 0.95~0.97；**blend 无增益**（同源）。

→ 之前的"分类崩"是某个具体坏配置（可能是分类 loss 下的 CTR 设定）造成的假象，**不是本质**。
这条 dogma 曾误导整条线。纠正后：模型族多样性(Logloss/GBM)重新可用，但因信号同源，**融合增益仍≈0**。

## 3. days×condition 生成过程：已被 vz19 完全吃透

label 率随 days↑、condition↓ 单调上升（10×10 分位热图光滑、无隐藏尖锐边界）。这正是 vz19 的
`ratio=days/cond_r` 信号。CatBoost+好 FE 在此达到 ~0.70，**没有留在桌上的边界规则**。

## 4. 为什么这意味着"必须换到数据之外"

- 数据内所有解耦轴(1–9)为负；建模上限 ~0.70 OOF。
- 冠军 online 0.749，按本赛 gap(~+0.01) 反推其 OOF-等价 ~0.736，**比数据内上限高 +0.03+**。
- 在**没有额外信息**的前提下，+0.03 AUC 在这种弱信号 tabular 上**信息论上不可得**。
- 故冠军几乎必然依赖 **(a) 外部数据**（本数据疑为半合成，schema 指纹：grades∈{s,ss,sss}、
  livability、age_range、max_g、cc、V + x0..x20 噪声投影 + 16-hex 随机 id；可匹配某公开原始集），
  或 **(b) 平台级泄漏**（提交反馈/顺序/文件外信息），二者都**不在本仓 CSV 内**。
- 已排除本地可复现的"可逆规则生成"：若 label 由少列确定性规则生成，CatBoost 早已 ≫0.70；实测封顶 0.70。

## 5. 给主人的战略重定向（诚实、可执行）

**不要**再在 CatBoost/ratio/rate/bagging/融合上投入——上限已封死在 ~0.713 online（本轮已证）。
真正能逼近 0.749 的，只有换到**数据之外**：

1. **确认赛制是否允许外部数据**。若允许：把本数据当"半合成指纹"，去匹配公开原始保险数据集
   （按连续列联合分布/边际直方图/类别基数指纹检索），拿回原始 label 或更干净特征。这是最可能的冠军路径。
2. **平台侧信息**：提交条数/时间戳/leaderboard 探针等（若规则允许），非 CSV 内结构。
3. 若两者都不允许 → 冠军 0.749 可能本身依赖违规/不可复现旁路；**现实可达的合法上限就是 ~0.713**，
   vz19 已在其上。此时理性目标是稳守 vz19，而非追不可复现的分数。
