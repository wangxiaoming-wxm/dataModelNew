# V5 工作原则（吸取 V3 教训）

## V3 为什么本地涨、榜上跌

| | V2 | V3 | 公开榜 |
|---|---:|---:|---:|
| 本地嵌套（监督者均值） | 0.69824 | 0.70124 | |
| 公开榜 | **0.71184** | 0.71064 | V3 **−0.00120** |

V3 唯一的改动是把 5 折换成 10 折。这让每折多看约 11% 训练数据，
**本地 OOF 估的是一个更强的预测器**，所以本地数字上涨；但提交到榜上的
排序相对 V2 几乎共线（Spearman 0.998），那点本地增益落在榜单噪声里还被反超。

结论：

1. **禁止再靠改 CV 折数 / 改上报口径来抬本地分。**
2. V5 的比较尺子必须与 V2 **逐字相同**：分层 5 折、固定树数、无验证折早停、
   预登记规则的嵌套选择（`src2/fuse.py` 的 `RULES` + 至多一条事先写明的新规则）。
3. 目标：在这把尺子下嵌套 OOF ≥ V2 + 0.002（≥ 0.70056 相对管道 0.69856，
   或 ≥ 0.70024 相对监督者均值 0.69824）。**达不到就不交付、不建议提交。**
4. 新臂进 `max` 的硬门：自身 bagged OOF ≥ **0.694**（`cat_alt2` 的反面教材）。
