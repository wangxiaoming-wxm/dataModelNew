# 历史文档（B5 / B6 / V10 / B7）

这个目录里的文件是**上一版方案**的文档，保留下来只为两个目的：
追溯当时的做法，以及说明为什么现在换了口径。

## 读之前必须知道的一件事

**这里所有的本地分数都用的是旧口径，不能和 `docs/RESULTS.md` 里的数字直接比较。**

旧口径把外层验证折同时用于「按 AUC 早停」和「产生 OOF 预测」
（`src/insurance_claim/train_b6.py:321`，参数见 `train_b5_focus.CAT_PARAMS` 里的
`eval_metric="AUC"` + `od_wait=150` + `use_best_model=True`）。
也就是说，在 1400 次迭代里直接挑那个让这一折 AUC 最高的点，再把这一折的预测拿去报分。

同一批折、同一份特征、同一组参数下实测的乐观偏差是 **+0.00254**
（原始输出见 `artifacts/v2/es_bias.json`）：

| 停止方式 | 单种子 OOF AUC |
|---|---:|
| 按验证折 AUC 早停（旧口径） | 0.68710 |
| 按验证折 Logloss 早停 | 0.68692 |
| 固定 500 棵树，完全不看验证折（新口径） | 0.68456 |

所以旧文档里的 B7 本地权威分 **0.702705** 不是一个可用于决策的数字。
把同一份 B6 `gap` 特征放进新口径重跑，4 个种子 bagged OOF 是 **0.69044**。

## 另外几处已经被推翻或需要改写的结论

`LESSONS.md` 里有几条在新的证据下站不住，接手的人不要照抄：

- **「异构 plus 臂（保留 x0–x18）与 B5/B6 corr≈0.91，是互补信号」** ——
  `x0`–`x17` 已经被证明是 `source` 的确定性函数加均匀噪声，
  组内残差对标签零预测力（见 `docs/DATA_STRUCTURE.md`）。
  plus 臂之所以有用，不是因为它带来了新信息，而是因为它是同一批信息的**另一套噪声编码**，
  起的是编码平均、降方差的作用。这个区别很重要，因为它决定了下一步该往哪走
  （造更多编码世界，而不是去挖 latent 里的"隐藏信号"）。
- **「LightGBM ~0.67 / XGBoost ~0.65 / EBM ~0.64，都不够强」** ——
  方向上没错，但当时的对照是在旧口径下做的，且没有给这些模型配折内嵌套目标编码。
  新版的 `lgb_te` 做到 0.671、`glm` 做到 0.665，和主臂的相关只有 0.89–0.93，
  是全场最解耦的两个臂。它们目前太弱所以进融合是负贡献，
  但**把它们做强是一条真实的路**（见 `docs/STRATEGY.md`）。
- **「12 seed 狂扩同质主臂，相对 8 seed 抬分极小」** —— 这条是对的，新版复核后同样结论。
- **「预注册离散融合 + 嵌套选规则」「max 有用」「禁止全局 TE」「不要把公开榜当调参反馈」** ——
  这几条完全正确，新版原样继承。
