## 5. 协议红线（监督者强制）

1. 外层验证折上**不许**早停或做任何选择；树数开跑前定死。  
2. 特征工程不许碰标签；分位 / 车型量纲 / 抖动流均为 label-free。  
3. 融合规则先登记再看分；主报是**多 block seed 嵌套均值**，不是单一种子或全量 OOF 冠军。  
4. 打乱标签必须回落到 ~0.5。  
5. 不要拿榜单分当调参反馈；不读测试集标签。

| 目标包装成 0.707 | Bayes≈0.706，当前 0.703 | **禁止**；目标门应保持失败直到真正达标 |

## 8. 坑（后人容易踩）

1. **`max` 对弱臂极敏感**：一个低 0.004 的臂偶尔把错误行顶到高位，全量看起来还行，嵌套会被误选拖垮。  
2. **F20 单臂可以弱于 F10，但与 F10 一起 max 仍可能涨**：不要只看单臂就杀多样性折方案。  
3. **种子从 8→16 平均 ≠ 再涨 0.002**：本数据 bagging 早饱和；新种子更适合作为**另一臂**进 max。  
4. **`audit_v4` 必须与 `fuse4.RULES` 同步**：否则监督者嵌套数和提交文件会对不上。现已 `from fuse4 import RULES`。  
5. **fast screen（400 树 / 5 折）只能排序，不能当主报**：过门槛后再跑完整 8 种子 × 目标折数。  
6. **B7 本地 0.7027 与本口径不可比**：含验证折早停乐观（约 +0.0025）。  
7. **公开榜 SE≈0.011**：本地 +0.002 不保证榜单同向同幅。

## 9. 下一步建议探索（若继续）

按期望收益排序；每条都必须先预登记规则、再跑、再过 `audit_v4`：

1. **完成并审慎评估 w12（main∪alt 特征并集）**  
   - fast 曾强于 main（约 +0.0035），完整 8 种子未跑完即停止。  
   - 门槛：bagged OOF ≥ main−0.003，且 `views_max_10_20_r16_r16b_w12` 嵌套 ≥ 当前 0.70303。  
2. **真正强的新编码世界**（不是微扰动）  
   - 必须在 mid-score 残差上拿出稳定单变量/交叉信号；相关 0.95 但弱 0.005 的世界对 `max` 有害。  
3. **校准风险函数后再估 Bayes**  
   - 若新分数把校准 Bayes 从 ~0.706 明显推高，才说明 0.707 仍有诚实空间。  
4. **不要优先**：再堆同质种子、再扫 CatBoost 超参、上 LGB/GLM/NN 当主力、伪标签、早停。

若 Bayes 复估仍 ≤0.706 且邻域同标率无提升，应承认 **0.707 诚实本地目标可能不可达**，把精力转到提交稳定性与榜单方差，而不是继续虚报本地分。
