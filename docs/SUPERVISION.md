# 诚实结论：本地 AUC 0.99999 在这份数据上不存在

> 监督者结论。数字全部可复现；没有一步依赖测试集标签或榜单反馈。

## 1. 请求与约束

请求是在**诚实且绝对不过拟合**的前提下，把本地 AUC 推到 0.99999。
本分支的协议红线（`docs/HANDOFF.md` §4）与 `src3/audit.py` 的独立审核门
把"不过拟合"落实成可执行的检查，而不是口号：

- 外层验证折上不允许早停或任何选择；
- 特征工程不许碰标签；
- 融合规则必须先登记再看分；
- 打乱标签后整条管线必须回落到 ~0.5；
- 嵌套选择必须对多个 block seed 稳健，不能只报某一个幸运种子。

bootstrap 95% CI = [0.6856, 0.7129]，隐含公开榜 SE ≈ 0.011。

## 3. 为什么 0.99999 达不到

四条彼此独立的证据，方向一致：

| 测量 | 结果 |
|---|---|
| 对已观测到的风险函数做完美建模，它自己能打到的 AUC | **0.70321** |
| 同一分数对从其自身拟合风险重抽的标签 | 0.70255 ± 0.00674 |
| 信号空间最近邻（最近 5%）同标签概率 | 0.830 vs 机会 0.765（lift +0.066） |
| 诚实分数的 top 1% 正例率 | 51% —— 恰好是 AUC≈0.70、患病率 10% 时的理论值 |

最近邻结果是决定性的：如果标签是特征的任何（哪怕极复杂的）函数，
几乎相同的行应当几乎总是同标签。它们只比机会高 6 个百分点。
**标签本身就是高度随机的**；要把 Bayes AUC 推到 0.99999，
要求正例处 p(x)≈0.99999、其余处 ≈0 —— 这份数据里没有这种结构。

泄漏排查（`hunt/h01_recon.py`）也关掉了"作弊捷径"：
id 是均匀随机 64 位、行序无信号、无重复特征向量、train/test 无重叠、
小数精度无生成器痕迹。

## 4. 0.99999 是怎么被造出来的（以及监督者如何抓住它）

`hunt/h05_why_not_one.py`：

| 手法 | 报告的本地 AUC | 同一代码、标签打乱后 |
|---|---:|---:|
| A. 全量拟合再在同一批行上打分 | **1.00000** | **1.00000** |
| B. 对 `id` 做全量目标编码，再跑 5 折 | **1.00000** | **1.00000** |
| C. 按相关筛 4000 个噪声列，再跑 5 折 | 0.67644 | 0.62887 |
| D. 本分支诚实管线 | 0.69910 | **0.4983** |

A/B 在标签被摧毁后仍报 1.0 —— 分数从来就不是来自特征。
监督者的打乱标签门（§2）和协议扫描就是用来拒绝这类数字的。
**在诚实协议下报告 0.99999，等于承认过拟合；两者不能同时成立。**

## 5. 在诚实协议下实际推到了哪里

| 步骤 | 诚实嵌套 OOF | 备注 |
|---|---:|---|
| 基线 `views_max`（提交 0.70878 的那版） | 0.69824 | 20 个 block seed 均值 |
| CatBoost 超参见屏（ordered / MVS / rsm / CTR / lr…） | ±0.001 | 全部落在噪声带内 |
| 新编码世界 w4 / w5（5 折） | 单臂 0.6886 / 0.6937 | 解耦够好，但弱于现有三臂；进 `max` 负贡献 |
| **10 折 CV 替换三个主臂** | **0.70124** | d5/d6/alt bagged OOF 分别到 0.6977 / 0.6976 / 0.6982 |

10 折是唯一跨过噪声带的一步：每折多看约 11% 训练数据，三个主臂各自 +0.002–0.003，
预登记的 `views_max` 全量 OOF 从 0.69910 到 **0.70151**，嵌套均值到 **0.70124**
（sd 0.00035，20 个 block seed）。提交文件：`submissions/submission_v3.csv`。

这已经贴着 §3 估出的 Bayes 天花板（0.703）：继续堆编码世界或换超参，
期望收益在 ±0.001 的噪声里。**0.99999 与 0.70 之间的缺口不是工程问题，是数据问题。**

## 6. 监督者的硬门：达不到目标不能交付为"达标"

`src3/audit.py --target 0.99999` 会让 `target_reached` 门失败。
§3 的证据成立期间，这个门会一直失败。迭代可以继续，
但**不会**把任何低于目标的数字包装成达标。
