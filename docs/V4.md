# V4 方案（进行中）

> 分支：`cursor/honest-auc-v4-145a`  
> 基线：V3 诚实嵌套 OOF **0.70124**（`docs/V3.md`，本分支不改动 V3 产物）  
> 目标：诚实嵌套 OOF（20 block seed 均值）**≥ 0.707**，且独立监督者全部诚实性门通过

V4 在 V3 的同一套诚实协议上继续推：不解冻早停、不碰测试标签、融合规则先登记再看分、
主报数字是多 block seed 嵌套均值。监督者代码在 `src4/audit_v4.py`，与工作管道隔离。

## 1. 起点与天花板（V4 复测）

| 口径 | 数值 |
|---|---:|
| V3 嵌套均值（20 seed） | 0.70124 |
| V3 `views_max` 全量 OOF | 0.70151 |

相对旧文档（V2 分数估出的 0.703），用更强的 V3 分数复估后天花板上移约 +0.0025。
目标 0.707 仍贴着天花板，必须找到**未吃干的信号或更接近 Bayes 的估计**，不能靠协议违规。

---

## 2. 协议红线（继承 V3，监督者强制）

1. 外层验证折上不许早停或做任何选择；树数开跑前定死。
2. 特征工程不许碰标签；分位 / 车型量纲 / 抖动流均为 label-free。
3. 融合规则先登记再看分；主报是多 block seed 嵌套均值。
4. 打乱标签必须回落到 ~0.5。
5. 不把榜单分当调参反馈；不读测试集标签。

`src4/audit_v4.py --target 0.707` 未达标则 `target_reached` 失败——设计如此。

### F20 融合登记

`cat_alt_f20` 进入。`src4/fuse4.py` 固定登记三条同构规则
`views_max_f20`、`views_mean_f20`、`views_half_f20`，以及一条
`views_max_10_20`（10-fold 与 20-fold 三强臂共同取 max）。最终仍以 20 个
block seed 的 nested selection 均值为主报。

### BAGSUB 登记

`src4/run_world.py` 增加 `--train-frac`，仅在每个外层训练折内部按标签分层固定抽样；
不读取 held-out fold 标签做模型选择，不传 `eval_set`，测试集仅被 label-free FE 使用。
首个固定方案为 `--train-frac 0.85`：

| arm | runner |
|---|---|
| `cat_d6_sf85` | `--world main --preset d6 --train-frac 0.85` |
| `cat_alt_sf85` | `--world alt --preset d6l6 --train-frac 0.85` |

`src4/fuse4.py` 预登记 `sub85_max` 与 `views_max_sub85`；臂不存在时自动跳过。

`sf85` 八种子最终结果（seed 24000..24007）：

| arm/rule | OOF / nested |
|---|---:|
| `cat_d6_sf85` arm OOF | 0.69163 |
